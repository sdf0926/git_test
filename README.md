# 즉흥 찬양 반주 프로그램 — 프로토타입

미가엘/셀라 같은 기존 교회 반주기의 한계(구간 이동이 자유롭지 않거나, 반복 전환이 부자연스러움)를
해결하기 위한 즉흥 찬양 반주 프로그램의 1단계 프로토타입입니다.

- 마디 경계에서만 전환되어 박자가 깨지지 않음
- 구간 버튼을 누르면 즉시 이동이 아니라 "예약" → 현재 마디가 끝나면 자연스럽게 이동
- 전환 직전 마지막 박에 다음 구간으로 이어주는 필인(드럼 필/베이스 패싱톤) 삽입
- `한 번 더` / `계속 반복`으로 실시간 반복 제어
- MuseScore(.mscz/.mscx) 악보를 그대로 불러와서 코드 심볼 기반으로 베이스/드럼/기타/패드를 자동 생성

## 파일 구조

- **`index.html`** — 메인 프로토타입. 이 파일을 브라우저에 더블클릭으로 열어서 실제로 사용합니다.
- **`midi_demo.html`** — 악기 음색 비교/실험용 데모 페이지. index.html에 반영하기 전에 여러 GM 음색·리듬
  패턴·이펙트를 먼저 들어보고 고르는 용도입니다. **작업 순서: 항상 이 데모에서 먼저 테스트한 뒤,
  마음에 드는 결과만 index.html에 반영합니다.**

두 파일 다 인터넷 연결이 필요합니다 (Tone.js, JSZip, GM 음원 샘플을 CDN에서 불러옴).
악보 파일(.mscz)은 저작권 문제로 이 저장소에 포함하지 않습니다 — 사용자가 직접 자신의 악보를 불러와서 씁니다.

## 사용 방법 (index.html)

1. `index.html`을 더블클릭해서 브라우저로 엽니다.
2. "악보를 불러오세요"에서 `.mscz` 또는 `.mscx` 파일을 선택합니다.
3. MuseScore에 `SystemText`(또는 RehearsalMark/StaffText)로 "Verse 1", "Chorus" 같은 라벨을 넣어두면
   자동으로 구간 버튼이 생깁니다. 라벨이 없으면 "+ 구간 추가"로 마디 범위를 직접 지정할 수 있습니다.
4. "재생"을 누르고, 재생 중 아무 구간 버튼이나 눌러서 즉흥으로 흐름을 바꿔봅니다.
5. 하단에서 템포/조옮김/악기 on-off(멜로디·베이스·드럼·패드·기타)를 조절할 수 있습니다.

## 현재 사용 중인 악기 (index.html)

| 파트 | 음원 | 비고 |
|---|---|---|
| 멜로디(피아노) | GM Acoustic Grand Piano (soundfont-player) | 악보에 적힌 멜로디를 그대로 재생 |
| 베이스 | GM Electric Bass finger | 코드 심볼에서 자동 생성 |
| 기타 | GM Acoustic Guitar (Steel) | 코드 심볼 기반 스트로크, 템포에 따라 "고고"/"슬로우 고고" 패턴 자동 전환 |
| 드럼 | 실제 GM 표준 드럼킷 샘플 (WebAudioFont, 킥/스네어/하이햇) | 스네어는 피치를 낮춰 먹먹한 톤으로 조정 |
| 패드 | Tone.js 신스 (배경 화음 워시) | 코드 심볼에서 자동 생성, 조용하게 깔림 |

## 오늘(2026-09-13) 진행 기록

1. **파싱**: .mscz(zip) → .mscx(XML) 파싱, 코드 심볼(TPC 기반)·가사·구간 라벨(SystemText) 인식.
   MuseScore가 페이지 나눔 때문에 한 마디를 `<Measure len="...">`로 쪼개 저장하는 경우를 자동으로
   다시 합치는 로직 추가 (안 그러면 반주가 마디 중간에 억지로 끊김).
2. **재생 엔진**: Tone.Transport 기반 lookahead 스케줄러로 마디 경계 전환 구현. 구간 버튼 클릭 →
   다음 마디 경계에서 예약된 전환 + 드럼 필인/베이스 패싱톤 삽입.
3. **가사 표시**: 한국어+일본어 병기, 각 언어 2줄(현재 줄 크게 강조 + 다음 줄 미리보기). 음절 붙여쓰기
   버그(악보 데이터에 띄어쓰기 정보가 없어서 생긴 문제) 수정.
4. **UI 톤 변경**: 네온/게임 느낌 색상 제거 → 앰버 단일 강조색 + 콘솔/채널스트립 스타일로 재디자인.
5. **악기 음원 교체**: 처음엔 Tone.js 합성 신스로 시작했다가, 미가엘 등 기존 반주기가 GM 웨이브테이블
   음원을 쓴다는 걸 확인하고 실제 GM 음원(soundfont-player + WebAudioFont)으로 전면 교체.
   - 피아노: 처음 전자피아노(FM 신스) 시도 → 사용자가 어쿠스틱 피아노 선호로 되돌림 → 최종 GM
     Acoustic Grand Piano로 통일
   - 베이스: 신스 → GM Electric Bass finger
   - 드럼: Tone.js 합성 → WebAudioFont 실제 GM 드럼킷 샘플. 스네어는 여러 피치/다른 녹음을 데모에서
     비교 후 선택
   - 기타: 신규 추가 (어쿠스틱 스트로크), 템포 기반 "고고"/"슬로우 고고" 패턴 자동 전환 + 강약·타이밍
     휴머나이즈 적용
6. **`midi_demo.html` 신설**: 악기별 GM 음색을 미리 들어보고 비교/선택하는 전용 페이지. 피아노(코드/
   멜로디 분리), 베이스, 드럼(스네어 톤 비교), 어쿠스틱 기타(스트로크 패턴 3종), 일렉 기타(파워코드)
   섹션 구성. **앞으로 악기/사운드 관련 실험은 이 파일에서 먼저 하고, 확정된 것만 index.html에 반영.**
7. **믹스 밸런스**: 기타/드럼이 피아노 대비 상대적으로 크게 들리는 문제 확인 → 피아노 게인 상향,
   기타 게인 대폭 하향(코드 폴리포니 때문에 같은 게인이어도 더 크게 들림), 드럼 볼륨 하향.

## 알려진 트레이드오프 / 다음에 결정할 것

- GM Acoustic Grand Piano는 범용 호환성 위주 음원이라, 이전에 썼던 Salamander 피아노 샘플(고품질
  녹음)보다 음질은 다소 단순합니다. 필요하면 언제든 되돌릴 수 있습니다.
- 패드 볼륨을 피아노 수준으로 올렸는데, 배경 화음 역할이라 너무 두드러지면 다시 낮출 수 있습니다.
- 실제 오디오 품질/레이턴시는 Claude가 직접 들을 수 없어 사용자가 귀로 확인 후 피드백을 주는 방식으로
  진행 중입니다.
